# Package artwork

Artwork is stored locally as WebP, at most 1,280 pixels on either side, with
aspect ratio and transparency preserved. Images use quality 85; the Expected
Parrot logo uses lossless compression. Keep each image below 200 KB.

When replacing artwork, resize without upscaling and encode from the original
source, rather than recompressing an existing WebP. Update references in both
`../../README.md` and `../index.html` if the filename changes. The AISS tutorial
also keeps a copy at `../tutorials/aiss/assets/aiss-artwork.webp`.
